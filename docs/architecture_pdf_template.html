Security Architecture, Isolation & Evaluation Loops
7. Security & Isolation Model

The security architecture enforces layered defense across request routing, retrieval queries, and LLM boundary containment:

Key controls:
• Row-Level Security (Postgres RLS) / Project Scoping: Scoped strictly by user_id / project_id — enforces isolation even against potential application query bugs.
• Prompt-injection defense: Material content and user messages are always passed as data fields in the LLM request (<document>, <user_input>), never concatenated into system instructions; tool-calls from the LLM are validated against a strict allowlist and schema before execution.
• Signed, expiring URLs: Expiring tokens for document storage access.
• Secrets Management: Secrets via environment variables / secret manager, never committed to git repository.
